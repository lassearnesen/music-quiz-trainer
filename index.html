First time? How to get a Client ID (2 min)
  1. Go to developer.spotify.com/dashboard and log in.
  2. Click Create app. Name it anything (e.g. "Quiz Trainer").
  3. In Redirect URIs, paste the exact Redirect URI shown above, then Add.
  4. For API, tick Web API and Web Playback SDK, then Save.
  5. Open Settings → copy the Client ID → paste it above.
  6. Playback needs Spotify Premium. Keep the Spotify app closed while playing to avoid spoilers.
